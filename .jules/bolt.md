## 2024-04-25 - [Debounce Search Performance]
**Learning:** Frequent setState updates triggered by text field onChanged events cause unnecessary UI re-renders and potential performance bottlenecks, especially when filtering long lists of items. The default approach for text fields was missing proper debouncing/throttling which is particularly critical in list views where multiple child components rebuild on state change.
**Action:** Created a Debouncer utility class utilizing dart:async Timer, implemented inside the widgets and controllers with search functionalities (calendar, streaming interface, and chat controller) with a 300ms delay. Remember to dispose of the Debouncer in the dispose method of states to prevent memory leaks or calling setState after a component is unmounted.
