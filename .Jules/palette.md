## 2026-04-23 - Adding Tooltips to Authentication Flow Icon Buttons
**Learning:** The Flutter IconButton widget does not provide default accessibility labels out of the box unless specified. This is especially problematic for dynamic icons like password visibility toggles, where screen readers need to know the state (e.g., 'Show password' vs 'Hide password').
**Action:** Ensure that all icon-only IconButton implementations throughout the app, particularly those that handle state changes, explicitly define the tooltip property with semantic, dynamic text.
