## 2024-05-24 - Debouncing TextField onChanged in Flutter
**Learning:** In Flutter, updating state on every keystroke within a `TextField.onChanged` callback can cause excessive widget rebuilds, redundant filtering operations, and unnecessarily trigger analytics events on partial inputs. While a `Debouncer` using `dart:async` `Timer` is a standard pattern, it's critical to remember to `dispose()` of the timer within the StatefulWidget's `dispose()` method to prevent memory leaks and the 'setState() called after dispose()' exception if the user navigates away while the timer is still active.
**Action:** Always wrap state updates and expensive operations triggered by high-frequency input events (like typing or scrolling) with a Debouncer, and explicitly manage the lifecycle of the Debouncer by disposing it when the owning widget is destroyed.
