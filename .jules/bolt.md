## 2024-06-11 - Content Aggregation Sequential Bottleneck
**Learning:** Iterating over multiple external API integrations (like social media platforms) sequentially creates an O(N) loading bottleneck, heavily degrading user experience as the number of connected platforms grows. Dart's `Future.wait` combined with `.map().toList()` allows concurrent fetching, reducing total fetch time to approximately O(max(platform response time)). Inside the `Future.wait` mapping, it's crucial to wrap each async task in a `try-catch` with `return await` so a single failure doesn't crash the entire `Future.wait` array and bring down the aggregation feature.
**Action:** Always prefer `Future.wait` over sequential loops for independent network calls or I/O bounds tasks. Ensure robust localized error handling around each mapped future.
