## 2024-06-12 - ContentAggregationService Sequential Fetching Bottleneck
**Learning:** Aggregating content across multiple platforms was using a `for` loop with sequential `await` calls, creating a severe performance bottleneck (O(N) latency) in the multi-platform architecture. By using `Future.wait()` on an iterable of async operations created with `.map().toList()`, platform fetches can execute concurrently, dramatically reducing total load time to the latency of the slowest platform.
**Action:** When performing independent network requests across multiple sources, always map them to a list of futures with `.toList()` to eagerly evaluate the iterable, and use `Future.wait()` to run them concurrently, wrapped in `try-catch` blocks returning `await` so individual failures don't fail the entire batch.
